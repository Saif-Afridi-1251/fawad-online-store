Fawad Online Store — Source Code

This archive contains the tracked source project, public images, dependency lockfile, database schema and migrations, and deployment configuration.

Local setup
1. Install Node.js 22.13 or later.
2. Extract this ZIP and open a terminal in fawad-online-store.
3. Run npm ci.
4. Copy .env.example to .env and configure the values for your environment.
5. Run npm run dev.
6. Run npm run build to build the application.

Server functions use Cloudflare bindings and external services. Configure your own database, storage, authentication, email, and payment settings as required by the included configuration and .env.example. Live orders, database records, uploaded storage files, and runtime secrets are not part of a source-code export. Some server features depend on the ChatGPT Sites hosting integration and require adaptation on another host.
